
## 词表说明

哈工大信息检索研究室同义词词林扩展版，基于《同义词词林》扩充，最终的词表包含 77,343 条词语。
其中《同义词词林》中保留下来的 39,099 条词语（原书共收词 53,859 条，剔除 14,706 个罕用词和非常用词）。

语料来源：人民日报 1998 年上半年的电子版。语料规模：从“北
大-富士通”语料中随机抽取 11331 句，约 35 万词语。

## 编码的方法

共8位编码（第1-3级和《同义词词林》保持一致）
- 第1级（第1位，大写英文字母）大类
- 第2级（第2位，小写英文字母）中类
- 第3级（第3-4位，二位十进制整数）小类
- 第4级（第5位，大写英文字母）词群
- 第5级（第6-7位，二位十进制整数）原子词群
- （第8位）=#@
    - “=”代表“相等”、“同义”。
    - “#”代表“不等”、“同类”，属于相关词语。
    - “@”代表“自我封闭”、“独立”，它在词典中既没有同义词，也没有相关词。
